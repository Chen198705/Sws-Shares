## 10. "8.8GB"数字最可能的来源（最终排查）

沈万三本身的日志仅 4.5MB，但用户提到 8.8GB 这个数字。最可能的来源是  下若干项目无关 cache 的加总：

| 路径 | 大小 | 是否沈万三 | 是否日志 |
|---|---|---|---|
|  | **12GB** | 否 | 否 |
|  | 2.2GB | 否 | 否（pip 包下载缓存） |
|  | 2.1GB | 否 | 否（pip 用户级包） |
|  | 101MB | 否 | 否 |
|  | 980KB | 否 | 否 |
|  | 830MB | 否 | 否 |
|  | 171MB | 否 | 否 |
|  | 172MB | 否 | 否 |
|  | 373MB | 否 | 否 |
|  | 327MB | 否 | 否 |
|  | 229MB | 否 | 否 |
|  | 2.0GB | 否 | 否（ComfyUI 项目） |

8.8GB 最有可能是以下几种加总：
- 12GB（Claude-3p）+ 某个子集 → 接近 8.8GB（不可能，因为已经超 8.8GB）
- pip cache（2.3G）+ Python lib（2.1G）+ Playwright（830M）+ Homebrew（171M）+ oMLX（172M）+ ComfyUI（2.0G）+ 其他 ≈ 7.6GB → 接近 8.8GB
- DaisyDisk / OmniDiskSweeper 等磁盘清理工具扫描时把多个 cache 加总后给出的"潜在清理 8.8GB"提示

**无论哪种解释，8.8GB 与沈万三的真实日志 4.5MB 完全无关**。沈万三的日志已被 rotation 守护（50MB size cap + 30 天保留 + truncate 不 mv），目前无需任何清理。
