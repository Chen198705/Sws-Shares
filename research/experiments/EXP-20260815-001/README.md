# EXP-20260815-001: mom_6_1 动量因子样本外验证

## 假设

H1：A 股截面动量（过去 6-1 月收益）在多数子周期显著为正。

## 方案

- Universe：随机抽样 50 只非 ST A 股（seed=42）
- 数据：AKShare 日线，2014-01-01 ~ 2024-12-31
- 切分：2014-2022 训练，2023-2024 样本外
- 方法：月度再平衡、T+1、次日开盘成交、涨跌停不可成交、计入印花税/佣金/滑点
- Baseline：BL1-BL4
